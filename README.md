# HauntedHouseEscape2026
Solutions to Mary Knoefel's 2026 SQL Haunted House Escape Challenge

Room 1: Find the sum of favorite_number for all ghosts who haunt the Entryway and whose name starts with 'B'
Room 2: Find the subject_name of the oldest portrait
Room 3: Find all course types where the average poison_level > 7
Room 4: Return the title and author name for every book written by an author who died before 1900
Room 5: Find the experiment_name of the experiment(s) with the highest success_rate
Room 6: Create a query that returns name, cause_of_death, and a new column peacefulness using: if cause_of_death = 'old age', then 'Peaceful', otherwise, 'Tragic'
Room 7: Use a window function to find all chimes where the volume increased compared to the previous chime.
Room 8: Find the door_name that can be opened by the key with the highest average power_level among successful attempts.
